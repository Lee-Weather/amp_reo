#### 2026-10-26 exp1.2异常姿态专项诊断

**2. AMP模仿分支未约束住策略。** 从CSV重建3帧AMP特征并加载checkpoint判别器，重算style_reward与CSV最大差约2.05e-7。专家样本判别分数中位数约+1.0012，策略约-0.9677，专家风格奖励均值约0.0400，当前回放仅0.001341。训练末轮任务/风格奖励分别0.029914/0.000617，模仿早已未收敛。

**3. 姿态与接触约束不完整。** 现有orientation项只约束base_link的重力投影，不直接约束lumbar_yaw或肩、腕相对默认姿态。静态偏转几乎不增加速度、加速度和action_rate代价；只要不越软限位且仍能跟踪速度，就可能获得较高任务回报。参考X1 AMP工程还包含arm_pitch_mean_offset、feet_slide、feet_distance_y、joint_energy等项，本次简化迁移未完整保留，碰撞惩罚也从参考配置-10变为-1。这不代表照抄即可解决所有姿态问题，但说明当前实现不是完整复刻参考训练目标。

速度核也容许明显跟踪误差：sigma=0.25时，指令0.6、实速0.3m/s仍有约0.698的线速度核；指令0.4而静止也有约0.527。没有足够姿态/风格约束时，速度任务不能保证自然步态。

**4. PD目标角经常超出硬限位。** 所有关节统一action_scale=0.25、动作裁剪±5，对应默认角周围±1.25rad（约±71.6度）的目标范围；控制器未逐关节裁剪目标角，仅裁剪力矩。按上述稳定样本计算：

| 关节 | 目标越硬限位比例 | 相关硬限位 |
| --- | --- | --- |
| right_wrist_pitch_joint | 76.8% | ±22.9度 |
| lumbar_pitch_joint | 51.8% | -8.6至25.8度 |
| left_ankle_pitch_joint | 44.9% | -23.5至20.1度 |
| left_wrist_pitch_joint | 41.3% | ±22.9度 |

这使部分关节长期顶着机械限位，不能靠只裁剪力矩保证目标姿态合理。全程记录到12196次关节力矩饱和事件，统计覆盖物理子步；占全部29×10×3000个关节子步约1.40%，并非每个控制步都全身饱和。它是明确的控制约束缺口，但不能单独解释所有腰肩偏置。

**5. 重置分布不一致加重了起步失稳。** 训练使用参考轨迹随机状态初始化，回放关闭RSI，采用平均关节姿态加随机偏差及固定根姿态，并新增1.5秒零速度缓冲；训练没有相同的强制缓冲。平均轨迹姿态作为动作零点，与“已验收的静态平衡站姿”不是同一件事。

非超时终止发生在42.14秒：根高度约0.120m、roll约83.2度、pitch约-35.4度。这是在40.02秒超时重置后的2.12秒，缓冲结束后约0.6秒。41.52秒末缓冲时已经出现vx约-0.419m/s及明显倾斜，说明该次恢复尚未稳定，不能全归因于之后的速度跳变。CSV未记录逐个非足接触终止标志，不能进一步断言究竟哪一个身体触地触发终止。

**6. 当前证据不支持先翻关节轴或重排动作。** 参考文件携带的关键点位置与当前URDF按关节名计算的FK最大误差约5.56e-7m；回放记录的双足世界坐标与当前URDF FK误差分别小于9.13e-7m、1.00e-6m。动作零点与参考均值最大差仅4.35e-5rad。轨迹小幅限位裁剪会带来最大约8.7mm的关键点变化，应保留为数据质量检查项，但尚无证据把主要的30—50度姿态偏移归于轴符号或关节排序错配。

**下一轮优先级**：先补逐关节合法PD目标范围及越界诊断，加入适合当前URDF的腰、上肢和髋部姿态软约束并补足足部接触/滑移约束；将默认站立初始化纳入训练验证，和RSI初态分别验收；随后对任务/风格数值尺度、判别器更新和正则化做小规模受控比较。不能只在当前目标下延长训练轮数，也不宜未经验证直接翻轴或冻结全部上肢。本次仅分析，未修改控制或奖励、未启动重训。


## 实验 exp_1.1：修正PD目标范围与异常姿态

编号说明：按用户本次指定使用exp_1.1；技术对照数据来自现有exp1.2（历史训练编号exp_ada_2），不改写已有实验编号，也不虚构exp_1训练结果。这轮为控制、奖励和初始化的组合修正，编号服从用户命名，修改编号独立列明。本节保留拟定方案，代码已按下述实现并完成短程功能验证；正式训练任务尚未创建，实际门禁结果见§7。

### 1. 上一实验结果与教训

数据源为exp1.2的model_6000.pt、60秒六段回放CSV及本笔记专项诊断：

- 稳定样本腰yaw均值-33.28度，参考均值-0.65度；左肩roll均值-38.51度，参考-9.16度。
- 右腕pitch原始PD目标越硬限位比例76.8%，腰pitch为51.8%，左踝pitch为44.9%。
- 回放平均任务/风格奖励0.044821/0.001341；风格平均数值贡献约2.9%。
- 60秒内1次非超时终止，发生于42.14秒，另有2次超时；重置后约2.12秒跌倒。

核心教训：限幅力矩不等于目标角合法；骨盆朝向和速度奖励不能保证腰、上肢、下肢姿态合理；平均轨迹关节角不等同于已验证的稳定站姿。本次先验证控制、姿态和初始化组合修正是否有效，不能据单次组合实验将改进归功于某一项。

### 2. 本轮修改目标

1. 实际送入PD的目标角始终位于当前URDF硬限位内，并显著降低策略持续要求越界的比例。
2. 消除持续扭腰、肩部外展和髋踝偏转，保留29关节控制及参考动作的自然变化。
3. 让训练覆盖回放采用的站立重置与起步过程，避免只在RSI初态有效。
4. 在以上修正后重新检验AMP风格是否改善，不以存活或总奖励替代步态验收。

本轮不翻关节轴、不重排关节、不换参考轨迹文件、不修改网络和判别器参数。验证后额外增加了新任务内的碰撞脚底高度对齐与根速度重算，原始文件和关节角不变，原因及范围见§7。并非断言这些参数最优，而是先减少同时变化的因素。足部滑移、足距等额外奖励留作后续独立比较。

### 3. 修改内容

### 修改一：逐关节PD目标限位及越界记录

在X1 AMP任务内部统一定义：

- `q_raw = q_default + action_scale * clipped_action + motor_offset`；如启用动作延迟，应使用延迟后的动作。
- `q_pd = clamp(q_raw, q_hard_lower, q_hard_upper)`。
- `tau = Kp * (q_pd - q) - Kd * dq`，随后保持现有力矩限幅。

硬限位从URDF/Gym原始属性单独保存，不能误把已经乘0.95的软限位再当硬限位重复缩放。保留action_scale=0.25、动作裁剪±5、原PD增益、armature和动作中心，便于比较。

新增raw_target_violation惩罚：`-0.5 * dt * sum((q_raw-q_pd)^2)`，在各物理子步求均值后按控制步计入，避免随decimation重复放大。其作用是让策略不再长期要求不可执行角度，不能只靠机械裁剪使越界指标表面归零。

CSV分别记录raw/effective目标、逐关节目标限幅次数和力矩饱和次数。新增控制语义写入新任务checkpoint元数据，拒绝将不兼容旧checkpoint作为新控制方案直接恢复；旧任务回放保持可用。

### 修改二：三个明确的柔性姿态惩罚

姿态中心采用已核验的参考均值及原q_default，不引入人工左右同号/反号规则。按各组关节位置偏差平方和计成本，不要求瞬时复现某一参考帧：

| 新奖励项 | 关节组 | 初始权重（乘dt前） |
| --- | --- | --- |
| waist_deviation | lumbar_yaw/roll/pitch | -0.5 |
| upper_deviation | 双侧肩、肘、腕，共14关节 | -0.10 |
| leg_lateral_deviation | 双侧hip_roll、hip_yaw、ankle_roll | -0.25 |

公式均为 `weight * dt * sum((q_group-q_default_group)^2)`。不对髋pitch、膝pitch、踝pitch增加均值姿态惩罚，保留主要迈步屈伸自由度。上述三项属于软代价，29个动作仍由策略输出，不冻结腰或上肢。

初始量级依据exp1.2的2593个稳定样本估算：三组新增每步代价分别约-0.00368、-0.00439、-0.00357，总计-0.01164，约为旧回放任务奖励均值的26%。这是同一份旧数据上的离线重算，未包含加入新控制后状态分布变化，不是新实验结果，也不保证收敛。其他原任务奖励及其权重先保持不变。

### 修改三：训练与回放一致的站立初始化

训练每次重置采用50%参考状态初始化、50%已验证站姿初始化：

- RSI分支：保持4段参考轨迹及现有参考历史设置。
- 站姿分支：从B1/B2中选取低根速度、低关节速度、双足近地的真实静止帧作为候选；核对根姿态、根高度和接触几何，通过PD静态测试后固定为站姿初态。不直接把全轨迹平均角度当作平衡站姿。
- 站姿分支先施加1.5秒零速度指令，再切换到已采样的正常指令；训练和play共用缓冲逻辑与观测指令更新方式，记录requested/applied/observed。
- 站姿随机关节扰动由当前±0.1rad收窄到±0.03rad，并裁剪到硬限位；根线/角速度初始化为0。RSI分支沿用参考速度，不统一清零。
- play基线使用同一个站姿、同一个缓冲和初始扰动幅度；另提供RSI回放用于定位初始化敏感性。

动作中心仍为原参考均值，站姿初态与动作中心分开记录。静态PD测试应令目标等于候选站姿；不能简单使用零动作，否则目标会回到原平均动作中心。

#### 小碎步与参考步态不一致的专项分析（2026-10-26）

**现象确认：最终策略形成了贴地、高频、小幅的腿部往复运动，未复现参考的完整摆腿。** 分析使用正式seed5诊断CSV，不改变模型、控制或回放。参考选择B3连续前进片段，剔除两端各0.5秒，并按训练加载器规则修正微小关节越限、对齐最低脚底+2mm。策略0.6指令窗口为23.6～29.8秒，避开超时重置、站姿缓冲与速度过渡；另复核两个0.4指令窗口。

| 指标 | B3连续前进参考 | 最终策略，0.6m/s指令 |
| --- | --- | --- |
| 实际机身前向速度 | 0.617m/s | 0.440m/s |
| 同一条腿主要往复周期 / 频率 | 1.23s / 约0.81Hz | 0.26s / 约3.85Hz |
| 左 / 右髋pitch摆幅 | 37.01° / 37.88° | 10.69° / 13.10° |
| 左 / 右膝pitch摆幅 | 52.02° / 51.62° | 6.04° / 9.99° |
| 左 / 右脚相对骨盆前后摆幅 | 38.86cm / 39.95cm | 7.12cm / 7.09cm |
| 左 / 右最低脚底高度P95 | 32.87mm / 22.44mm | 3.45mm / 4.55mm |
| 两脚最低脚底同时低于1cm的帧占比 | 43.50% | 100% |
| 每个同腿周期机身前进距离 | 75.94cm | 11.43cm |

摆幅均为P95-P05；频率是同腿关节振荡频率，不是双腿落脚计数。每周期前进距离由机身均速乘周期估算，不是实测落脚点步长。脚底高度使用URDF与原始碰撞网格最低顶点重建；重建脚部link原点与CSV的最大误差7.60e-7m。两脚低于1cm是几何指标，不等于受力双支撑；策略该窗口实际两脚足部接触力均>20N的比例为59.35%。这些结果支持低离地、短摆幅，尚不能仅凭它们断言持续滑脚。参考与策略实际速度不同，表格没有将其伪装成同速度对照；但参考包含0.617m/s，0.6指令并未超过参考前进速度覆盖。

两个0.4指令窗口也呈同样模式：实际速度约0.25m/s，同腿周期约0.32s（3.13Hz），脚前后摆幅约5.4～5.9cm，最低脚底高度P95约2.1～2.8mm。因此不是单次指令切换或重置造成的短暂小步。

**不能简单归因为动作尺度太小。** 同一0.6窗口，左髋有效PD目标摆幅61.46°，实际髋摆幅10.69°，两者主频均约3.87Hz；右髋目标摆幅44.07°，实际13.10°，目标还包含约7.58Hz的显著高次谐波。左右膝目标摆幅13.73°/16.94°，实际6.04°/9.99°。策略在部分关节发出幅度较大且变化很快的目标，但实际受惯性、阻尼和接触约束，只形成小幅运动。右膝平均38.51°、左膝19.46°，还存在明显不对称。目标与实际的差异是实测事实；是否需要调整PD增益，必须进一步用受控跟踪测试或消融判断，不能直接据此放大增益或action_scale。

**原因判断分为证据和推断：**

1. **AMP没有保持住参考运动分布，是最直接的训练证据。** 最终回放style均值0.0004056，数值份额约0.90%（不等于策略梯度份额）；训练后半段expert/policy分数逼近+1/-1，style从2818轮附近0.003262降到最终100轮0.00033894。判别器能分清策略与参考，但策略未因此恢复参考步态。结合小摆幅和低离地，推断策略更偏向容易维持的任务动作，而非完成模仿。仅调高风格权重是否足够，仍需实验。
2. **任务奖励允许偏慢的小碎步继续获得较高分。** 当前速度项为exp(-速度平方误差/0.25)。只考虑前向速度从0.6偏到0.44，速度奖励因子仍约0.90；它奖励速度结果，没有直接要求参考的步幅、屈膝和离地。现有生效奖励未包含足部离地或腾空时间项；在AMP失效时，缺少其他机制排除这种运动。关节速度、加速度等成本也可能增加大幅摆腿的代价，但本次未分项消融，不能认定它们是单独根因。
3. **高频目标与实际运动脱节，且部分目标反复被裁剪。** 全回放右髋roll/腰pitch/左髋roll原始目标裁剪率为80.37%/77.27%/46.33%，会改变执行目标的波形；同时髋pitch即使未被裁剪，仍存在明显高频跟踪差异。因此不能把全部小碎步归因于硬限位。当前是50Hz策略、500Hz物理/PD且无LPF；滤波可能衰减高频，但不能单独生成正确的屈膝和摆腿周期，也不能仅在回放中加滤波后当作原策略验收。
4. **时间上下文与更新幅度是次级待验证因素。** AMP只看3帧，首尾跨度40ms，相对B3约1.23秒周期很短，对整周期节律的显式上下文有限；短窗口不代表AMP必然失败。后半段KL增大、固定学习率且在epoch末才检查最后小批次KL，可能加剧步态漂移；目前尚无单变量证据确定其因果贡献。

**后续优先顺序：** 先将model_2800/model_3200与model_6000按相同指令、种子和上述步态指标回放，确认中期是否保留更接近参考的周期；再分别验证PPO更新幅度与判别器/风格激励平衡。控制端用低频参考目标跟踪测试区分可执行性与策略主动选择的高频运动。若AMP恢复后仍低离地，再考虑与参考一致的轻量摆脚/腾空约束及速度奖励调整；不同时叠加所有改动，也不盲目固定所有速度下的步频。

可复现工具：[analyze_gait.py](../../scripts/amp_tools/analyze_gait.py)。完整数值见[gait_comparison.json](exp_1.1_evaluation/gait_comparison.json)，波形与摆幅见[步态对比图](exp_1.1_evaluation/gait_comparison.png)。本次只增加离线分析工具和记录，未修改训练算法、奖励、PD参数或正式三件套。

## 实验 exp1.3：仅x速度指令与AMP步态恢复

### 1. 上一实验结果与教训

exp_1.1最终6000轮：0.6m/s指令段实际约0.440m/s、速度RMSE约0.165m/s，同腿周期0.26s（3.85Hz）；膝摆幅6～10°、脚相对骨盆前后摆幅约7cm、脚底高度P95仅3～5mm。B3参考对应约0.81Hz、膝摆幅52°、脚前后摆幅39～40cm、脚底高度P95为22～33mm。

**从代码确认的训练机制缺口：**

- x指令由X1AMPEnv覆盖后的连续均匀采样生成，不使用基类的0.2m/s小速度清零；因此常规重采样没有专门的精确零指令占比，站姿重置后仅1.5秒零速缓冲。50%站姿初始化并不等于50%训练时间站立。
- 有速度跟踪、姿态、全局关节速度/动作变化代价，但没有零速专用的静止姿态/关节运动目标。局部速度正负抵消或小幅摇摆，仍可能取得较高速度跟踪收益。
- AMP判别器只看动作历史，不看速度指令；专家按四段等权全相位采样。运动风格与静止任务可能不相容；目前尚未用消融证明AMP是晃动的唯一诱因。
- 原始目标裁剪能保护执行，但不会自动教会策略输出静止且可执行的目标。当前回放没有动作LPF，增加LPF本身不修复目标与采样缺口。

**exp1.4建议：优先用现有模型热启动后继续优化，不从零重学。** 当前同腿频率已从exp_1.1的3.85Hz改善到1.25Hz，前向行走与站姿存活能力已有价值；末1000轮KL均值0.01119、RSI回合后期改善，没有证据表明模型已发生不可恢复的优化发散。问题更符合静止目标、参考/指令采样及左右脚执行状态未对齐，单纯原配置再加6000轮不能针对修复。

建议先在exp1.4中实现以下静止相关修正，再短阶段续训对照，控制与动作/观测约定保持一致：

1. 每次命令重采样约20%事件给精确零速，完整保持一个6秒周期；其余继续vx=[-0.2,0.65]，vy=wz=0。零速初始化从低运动状态选取，RSI行走初态与指令方向/速度匹配，历史和关节状态保持同相位。这里20%是重采样事件比例，不冒充实际训练步数比例。
2. 零速条件下单独约束根线/角速度、关节速度与相对站姿参考的偏移；站姿参考使用已验证的低运动姿态，不强行贴行走平均角，也不要求左右关节角时刻相等。允许小幅平衡修正；停止后平滑加大静止项，避免一条指令立即强制冻结所有关节。行走抬脚项在零速关闭。
3. 检查并适当增加真实低运动专家窗口，使零速目标与AMP分布相容；保持既有258维AMP特征、观测和动作约定，不因本轮修复给判别器随意添加输入。右脚完整摆动、膝踝目标越界与持续偏航作为行走验收保留，避免靠压住所有运动掩盖问题。

## 实验 exp1.4：零速静止目标与指令匹配初始化，热启动续训1000轮

### 1. 上一实验结果与教训

exp1.3完成6000轮；同腿周期约0.80秒，相比exp_1.1的0.26秒改善，但右脚最低脚底高度P95仅2.64mm。零速54～59.8秒内，根pitch P95-P05为7.27°，左右膝13.48°/11.59°；初始尚未行走时亦有15.27°/12.49°膝摆幅。末1000轮KL均值0.01119，无持续优化发散证据。核心教训：速度接近零不等于静止；需补足持续零速采样、静止约束及参考/指令相容性，同时继承已学步态。

### 2. 本轮修改目标

减少零速身体与关节晃动，减少RSI初始速度与指令冲突，保留前进行走能力。使用exp1.3最终模型作为起点，独立exp1.4任务新增1000轮；固定seed=5、4096环境。零速及行走验收见§6。

### 3. 修改内容

### 修改一：精确零指令与匹配初始化

每次命令重采样以20%概率给三轴全零，保持一个6秒周期；其余仍连续采样vx=[-0.2,0.65]、vy=wz=0。20%为采样事件概率，不等同实际零指令步数比例；固定范围的评估命令不被随机替换。站姿/RSI初始化概率仍为50%/50%，站姿保留1.5秒缓冲；RSI先取指令，再选局部vx差≤0.15m/s的真实参考状态，|命令vx|>0.05时还要求同方向。零速RSI选择完整低运动历史，禁止只把动态状态的根速度清零。

### 修改二：零速专用奖励

精确零指令下，门控由0随持续时间线性增加，0.5秒达到1；非零指令门控为0。姿态参考沿用已验证的standing_state，不改变策略动作中心或站姿元数据。以下为未乘dt的奖励scale，基类统一乘dt，最终与AMP按0.5/0.5混合。

| 新增项 | 代价定义 | scale |
| --- | --- | --- |

| stand_ang_vel | 全三轴角速度平方和/0.3² | -0.1 |
| stand_dof_vel | 29关节速度平方均值/0.5² | -0.2 |
| stand_pose | 相对站姿关节角误差平方均值/0.2² | -0.3 |
| stand_orientation | 相对站姿投影重力误差平方和/0.1² | -0.2 |

在exp1.3主回放890个后段零速样本上，满门控新增每步任务代价均值-0.01125，旧任务奖励均值0.04842，约23.2%；混合后变化约-0.00563。该结果是旧数据离线量级校准，不是exp1.4已训练效果，见[reward_calibration.json](exp1.4_evaluation/reward_calibration.json)。
